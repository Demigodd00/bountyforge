# Security policy

## Supported release

BountyForge `3.1.1` on StudioNet is the supported test release. StudioNet uses simulated GEN; this repository does not claim mainnet readiness or independent audit coverage.

## Reporting a vulnerability

Use GitHub's private security-advisory flow for this repository. Do not include private keys, seed phrases, wallet exports, or other secrets in an issue, pull request, screenshot, or chat.

Include the affected contract method or frontend path, expected and observed behavior, reproduction steps that use test accounts, and any public transaction hash. Do not test against wallets or funds you do not control.
